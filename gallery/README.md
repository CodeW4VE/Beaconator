# Screenshots for the Modrinth gallery

Drop images in here and they get uploaded. Nothing in this folder is published by itself.

Wanted, in the order they should appear on the page:

1. `01-beams.png` — the perimeter from the air at dusk or night, with red beams standing over
   the unbuilt nodes and a few green ones behind you. This is the money shot: it is the thing
   nobody else's mod does.
2. `02-map.png` — the Map tab, zoomed so the whole grid fits, with a mix of pending, excluded
   and dropped nodes so the colours read.
3. `03-yellow.png` — close to a node whose pyramid is up and is one beacon short, so the yellow
   beam is next to a green one. Sells the feature in one image.
4. `04-materials.png` — the Materials tab with real numbers on it.
5. `05-shared.png` — the Server tab with a plan in the list.

Full screen, no Discord or other windows in frame, F1 to hide the vanilla HUD if it clutters
(the mod's own HUD should stay).
