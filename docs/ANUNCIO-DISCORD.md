## 2. Announcement

**Body:**

```
# Beaconator
**Spawn proofing, without the spreadsheet.**

You know the drill: you want a perimeter, so you place one beacon, count to 101, place another, lose count, and three days later you find the one hole that is still spawning phantoms at you.

Beaconator is a mod we built for exactly that job. Drop the centre down and it works out where every other beacon goes, then follows you around telling you what is left.

**What it actually does**

:red_square: **Beams to the sky** over every beacon that is missing, so you can see where to dig from the far side of the site. Red is nothing, yellow is started, green is done.
:yellow_square: That yellow matters more than it sounds. A pyramid that is up and one beacon short looks finished from any distance, and you find out when the mobs do.
:map: **Its own map** to plan on, one pixel per block, drawn from wherever you have flown. Click nodes to drop them, shift drag for whole rows.
:green_square: **Real coverage**, exactly the volume the game applies effects in, so holes are visible instead of theoretical.
:bricks: **It does the maths.** Four beacons on a node in a square instead of a row is 20 blocks less per node. Over a perimeter, that is thousands of emerald blocks you do not have to farm.
:handshake: **One plan for everyone.** The smp runs it server side, so share your plan and the rest of us see every node you finish, live.

**Get it**

Jar and a proper guide: https://mine.w4ve.xyz/mods
It is in the modpack too, so if you keep that updated you already have it.

Open the screen with **Shift + B**. Press **G** if the beams get in your way.

Source, MIT: https://github.com/CodeW4VE/Beaconator
```
